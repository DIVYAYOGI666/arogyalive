# आरोग्य वार्ता - Hindi Health Blog

एक आधुनिक, सुलभ और विश्वसनीय हिंदी स्वास्थ्य ब्लॉग जो परिवार के रोजमर्रा स्वास्थ्य फैसलों में मदद करता है।

## 📋 विशेषताएं

- **हिंदी में व्यापक स्वास्थ्य जानकारी** - डायबिटीज, ब्लड प्रेशर, थायरॉइड, प्रेग्नेंसी, पोषण, इम्युनिटी और वजन पर लेख
- **उत्तरदायी डिजाइन** - सभी डिवाइस (डेस्कटॉप, टैबलेट, मोबाइल) पर परिपूर्ण
- **इंटरैक्टिव लेख ड्रॉअर** - चिकनी, उपयोगकर्ता-अनुकूल अनुभव
- **खोज कार्यक्षमता** - लेखों को हिंदी में खोजें
- **FAQ अनुभाग** - सामान्य स्वास्थ्य सवालों के उत्तर
- **पहुंच मानकों का पालन** - ARIA लेबल, कीबोर्ड नेविगेशन, स्क्रीन रीडर समर्थन
- **SEO अनुकूलित** - Sitemap, Open Graph मेटा टैग, स्कीमा मार्कअप
